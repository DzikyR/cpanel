Cara membuat API Token
  1. Buka dash.cloudflare.com → My Profile → API Tokens → Create Token → Create Custom Token.
  2. Permissions:
    • Account · Cloudflare Tunnel · Edit
    • Zone · Zone · Edit (Read cukup bila tidak menambah domain dari panel)
    • Zone · DNS · Edit
    • Untuk menu Email: Account · Workers Scripts · Edit, Zone · Email Routing Rules · Edit, Zone · Zone Settings · Edit
  3. Zone Resources: Include · All zones from an account (agar semua domain, termasuk yang ditambahkan nanti, terjangkau).
  4. Create Token, salin, lalu tempel di atas.
