🌐 Membuat website

  1. Buka menu Website.
  2. Di Tambah Website, isi subdomain (mis. prodi) lalu pilih domain dari daftar, misalnya informatikatsu.my.id → hasilnya prodi.informatikatsu.my.id. Kosongkan subdomain untuk memakai domain utama.
  3. Biarkan Publikasikan via Cloudflare tercentang agar website langsung online dengan HTTPS.
  4. Klik + Buat Website. Panel membuat folder /var/www/<domain>/public_html berisi halaman contoh.

Di Daftar Website tersedia tombol Nonaktifkan/Aktifkan, Hubungkan Git, Publikasikan/Cabut Publik, dan Hapus.

Website baru biasanya bisa dibuka 1–2 menit setelah dibuat (menunggu DNS Cloudflare).
Saat menghapus, panel menanyakan dua kali. Pertanyaan kedua menentukan apakah file dan database ikut dihapus. Pilih "Cancel" pada pertanyaan kedua bila hanya ingin menghapus konfigurasinya.

📁 Mengunggah file project

Semua file website ada di menu File Manager, mulai dari folder /var/www. Klik nama domain → public_html. Isi folder public_html inilah yang tampil di browser.

Cara tercepat: unggah ZIP lalu ekstrak

  1. Di komputer Anda, kompres isi project menjadi .zip. Kompres isinya (index.php/index.html dan folder lain), bukan folder induknya, agar file tidak masuk ke subfolder.
  2. Di File Manager, masuk ke <domain>/public_html.
  3. Hapus halaman contoh index.php buatan panel (tombol Hapus).
  4. Klik Choose File, pilih file ZIP, lalu ⬆ Upload. Maksimal 512 MB per unggahan; bisa memilih beberapa file sekaligus.
  5. Pada baris file ZIP, klik Ekstrak. File yang sudah ada dengan nama sama akan ditimpa.
  6. Hapus file ZIP-nya setelah selesai, lalu buka website untuk mengecek.
Kalau setelah ekstrak file berada di public_html/nama-project/, berarti ZIP berisi folder induk. Website akan terbuka di /nama-project/. Hapus folder itu, kompres ulang isi project, lalu unggah dan ekstrak lagi.

Lainnya di File Manager

  • + Folder dan + File: buat folder/file baru di folder yang sedang dibuka.
  • Edit: ubah file teks (PHP, HTML, CSS, JS, .env…) langsung di browser, lalu Simpan. File di atas 2 MB atau file biner tidak bisa diedit.
  • Unduh: simpan file ke komputer Anda.
  • Rename: ganti nama file/folder (di folder yang sama; tidak untuk memindahkan). Hapus: folder dihapus beserta isinya.

Konfigurasi koneksi database

Buat database di menu Database, lalu isikan ke file konfigurasi project (mis. .env, config.php):

  • MySQL/MariaDB: host localhost (atau 127.0.0.1), port 3306
  • PostgreSQL: host 127.0.0.1, port 5432

Untuk mengimpor file .sql besar, cara termudah adalah memasang phpMyAdmin dari menu Aplikasi.

⎇ Deploy dari GitHub

Lebih praktis daripada unggah manual bila kode project ada di GitHub: setiap git push website ikut terbarui.

  1. Menu Website → Hubungkan Git pada website tujuan.
  2. Isi URL Repo dan Branch (mis. main). Repo publik: URL https://github.com/user/repo.git. Repo privat: URL SSH git@github.com:user/repo.git, lalu tempel Deploy Key yang ditampilkan ke GitHub (repo → Settings → Deploy keys).
  3. Folder publik: kosong bila index.php/index.html ada di root repo; public untuk Laravel; dist/build untuk hasil build.
  4. Perintah setelah deploy (opsional), mis. composer install --no-dev. Untuk Laravel klik Isi preset Laravel.
  5. Klik Hubungkan & Deploy dan lihat log-nya.

Auto deploy: salin Payload URL dan Secret dari bagian Auto Deploy ke GitHub (repo → Settings → Webhooks → Add webhook, content type application/json).

Bila repo punya .env.example, panel otomatis membuat database MySQL + file .env dan mengimpor database/*.sql saat deploy pertama.
Deploy menimpa folder repo dengan isi GitHub. Jangan mengedit file kode langsung di server untuk website yang terhubung Git; ubah di GitHub lalu push.

🧩 Aplikasi sekali klik

  1. Menu Aplikasi → pilih aplikasi: WordPress, OJS, Moodle, Laravel, Joomla, Drupal, SLiMS, phpMyAdmin, atau Webmail.
  2. Pilih domain (website baru dibuat otomatis), isi judul situs, username, email, dan password admin.
  3. Klik 🚀 Pasang. Halaman detail menampilkan log; tunggu sampai status terpasang.
  4. Halaman detail berisi alamat website, halaman admin, login admin, dan data database.
Aplikasi hanya bisa dipasang di website yang masih kosong (belum dipakai Git, aplikasi lain, atau Node.js).

🟢 Aplikasi Node.js

  1. Menu Node.js → Buat Aplikasi Node.js: pilih domain, versi Node, dan folder aplikasi (bawaan nodeapp).
  2. Pilih Database bila perlu (PostgreSQL dan/atau MySQL); kredensialnya otomatis masuk ke environment.
  3. Klik 🟢 Buat Aplikasi. Bila folder kosong, panel membuat contoh server.js.
  4. Unggah kode Anda ke /var/www/<domain>/nodeapp lewat File Manager (ZIP → Ekstrak) tanpa folder node_modules, atau isi folder repo lewat Git Deploy.
  5. Di halaman aplikasi, klik npm install (atau npm install + build). Aplikasi otomatis di-restart.
Aplikasi wajib mendengarkan port dari process.env.PORT, contoh: app.listen(process.env.PORT). Port ditentukan panel.
  • Perintah start: npm start, node app.js, npx next start (Next.js), node .output/server/index.mjs (Nuxt).
  • Environment: isi KEY=VALUE per baris (pengganti file .env), lalu Simpan & Restart.
  • Database PostgreSQL tersedia sebagai DATABASE_URL (siap untuk Prisma, Drizzle, Sequelize, pg).
  • Skrip lain di package.json (mis. migrasi prisma migrate deploy) dijalankan lewat npm run.
  • Log aplikasi menampilkan output console.log dan error; cek di sini bila website menampilkan "Aplikasi Node.js sedang tidak berjalan".
  • Versi Node lain (18/20/22/24) dipasang dari bagian Versi Node.js.

🗄️ Database

  1. Menu Database → Buat Database.
  2. Pilih jenis: MariaDB / MySQL atau PostgreSQL.
  3. Isi nama database (huruf, angka, underscore), nama user, dan password (kosongkan agar dibuat acak).
  4. Klik + Buat. Catat password yang muncul; password tidak ditampilkan lagi.

✉️ Email

Persiapan (sekali saja, oleh admin)

  1. Token Cloudflare perlu izin tambahan: Workers Scripts: Edit, Email Routing Rules: Edit, Zone Settings: Edit.
  2. Menu Email → Pengaturan → isi SMTP login, SMTP key, dan API key Brevo → Simpan.
  3. Klik Pasang Worker (buka panel lewat alamat https).
  4. Pasang Webmail dari menu Aplikasi, mis. di webmail.informatikatsu.my.id.

Membuat alamat email

  1. Menu Email → pilih domain → + Aktifkan Email.
  2. Di Kotak Surat, isi nama (mis. prodi), password minimal 8 karakter, dan kuota → + Buat Kotak Surat.
  3. Buka webmail, login dengan alamat lengkap (prodi@domain) dan password tersebut.
  • Forwarder: teruskan alamat ke alamat lain, mis. info@ → beberapa dosen atau ke Gmail.
  • Kirim Email Tes untuk memastikan pengiriman bekerja; status pengiriman terlihat di log.
  • Aplikasi di server dapat mengirim email lewat SMTP 127.0.0.1 port 587 tanpa TLS, login alamat email + password kotak surat.
Dari luar jaringan, email dibuka lewat webmail. Aplikasi email di HP/Outlook (IMAP/SMTP) belum bisa tersambung karena server tidak membuka port ke internet.

💾 Backup & restore

  • Menu Backup → Backup sekarang per website, atau 💾 Backup semua website. Satu berkas .tar.gz berisi file website, database (MySQL & PostgreSQL), kotak surat email, dan pengaturannya.
  • Atur jadwal harian/mingguan dan jumlah cadangan yang disimpan.
  • Unduh berkas backup dan simpan di tempat lain (Google Drive, laptop) sebagai cadangan di luar server.
  • Restore: pilih backup dari daftar atau unggah berkas, isi domain tujuan bila ingin dipulihkan ke domain lain. Centang Timpa bila website tujuan sudah ada.
Lakukan backup sebelum perubahan besar (update aplikasi, import database, deploy versi baru).

☁️ Cloudflare

Website dipublikasikan lewat Cloudflare Tunnel, sehingga server tidak perlu IP publik atau membuka port. HTTPS ditangani Cloudflare.

  • Menu Cloudflare menyimpan API token dan menampilkan rute tunnel yang aktif.
  • Izin token minimal: Zone: Read, DNS: Edit, Cloudflare Tunnel: Edit. Untuk email tambahkan izin di bagian Email.
  • Website yang belum online: menu Website → Publikasikan.

⚙️ Services, Logs, Password

  • Dashboard: pemakaian CPU, RAM, disk, dan status layanan.
  • Services: start/restart/stop nginx, PHP, MariaDB, PostgreSQL, Postfix, Dovecot. Restart layanan bila website error setelah perubahan konfigurasi.
  • Logs: log akses & error nginx per website dan log PHP. Tempat pertama untuk mencari penyebab error 500.
  • Ganti Password: ganti password login panel secara berkala.

❓ Masalah umum

Website menampilkan halaman "Website aktif. Dibuat oleh LocalPanel"

File project belum ada di public_html atau halaman contoh index.php belum dihapus.

403 Forbidden

Tidak ada index.php/index.html di folder publik. Biasanya file terekstrak ke subfolder; lihat bagian mengunggah file.

500 Internal Server Error

Ada error di kode atau konfigurasi (mis. koneksi database salah). Cek menu Logs → <domain>.error.log.

Website tidak bisa dibuka dari internet

Pastikan kolom Publik di menu Website berstatus 🌍 Online; bila tidak, klik Publikasikan. Tunggu 1–2 menit.

"Aplikasi Node.js sedang tidak berjalan" (502)

Buka menu Node.js → aplikasi → Log aplikasi. Penyebab umum: belum npm install, perintah start salah, atau aplikasi tidak memakai process.env.PORT.

Upload gagal

Batas unggahan 512 MB. Untuk berkas lebih besar, pecah ZIP-nya atau gunakan Git Deploy.

Email tidak masuk/terkirim

Buka menu Email → domain → cek Status (Cloudflare & Brevo harus ✓), klik Sinkronkan, lalu lihat Log email.
